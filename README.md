# Spotify Sorter

Ett kommandoradsverktyg som sorterar dina egna Spotify-spellistor efter artist eller releasedatum, eller slumpar ordningen. Originalet kan sorteras om utan att först tömmas, alternativt kan verktyget skapa en privat kopia.

## Kom igång

1. Skapa en app i Spotify Developer Dashboard.
2. Kopiera `.env.example` till `.env` och fyll i dina uppgifter.
3. Installera beroenden: `pip install -r requirements.txt`
4. Kör: `python spotify_sorter.py`

Hemligheter i `.env` ska aldrig checkas in i Git.
